## Smart Waste Management System

- Classify waste into following six category :- cardboard, metal, plastic, paper, trash.
- Dataset from Kaggle :- [dataset](https://www.kaggle.com/datasets/farzadnekouei/trash-type-image-dataset/data)
- Base model used :- [EfficientNetV2 models](https://keras.io/api/applications/efficientnet_v2/efficientnet_v2_models/)
